# Limits und Einschränkungen

## Limits und Einschränkungen {id="chestprotect-limits"}

### Limits {id="chestprotect-limits-limits"}

Auf dem Server gelten folgende Limits pro Spieler:

| Typ                 | Maximale Anzahl |
|---------------------|-----------------|
| Container-Sicherungen | 250           |
| Entity-Sicherungen    | 100           |
| Gruppen               | unbegrenzt    |
| Mitglieder pro Gruppe | 20            |

Im Hauptmenü (`/chestprotect`) siehst du, wie viele Sicherungen du bereits besitzt. Hast du ein Limit erreicht, hebe nicht
mehr benötigte Sicherungen auf oder wende dich an das Team.

### Kosten {id="chestprotect-limits-costs"}

Das Sichern von Objekten kostet auf dem Server **kein Geld** und keine Items. Beim Aufheben einer Sicherung gibt es
deshalb auch keine Rückerstattung.

### Einschränkungen {id="chestprotect-limits-restrictions"}

- **Hopper:** An gesicherten Objekten funktionieren keine Hopper. Es können weder Items hinein noch heraus
  transportiert werden.
- **Teleportation:** Du kannst dich nicht zu einer Sicherung teleportieren.
