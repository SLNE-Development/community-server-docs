# Gruppen

## So nutzt du Gruppen {id="chestprotect-groups"}

Mit Gruppen verwaltest du vertraute Spieler für viele Sicherungen gleichzeitig. Statt demselben Spieler auf jeder Truhe,
jedem Fass, jeder Tür oder jedem Hopper einzeln zu vertrauen, fügst du ihn einer Gruppe hinzu und weist der Gruppe
deine Sicherungen zu.

1. Gib `/chestprotect` ein und wähle **Groups**.
2. Hier kannst du Gruppen erstellen, bearbeiten, ihre Spieler verwalten und Sicherungstypen festlegen.
   ![chestprotect-groups](chestprotect-groups.png) {border-effect="rounded" thumbnail="false" width="480"}

## Gruppenspieler {id="chestprotect-group-players"}

Jeder Spieler in einer Gruppe wird automatisch auf allen Sicherungen vertraut, die dieser Gruppe zugewiesen sind. Das
eignet sich z. B. für gemeinsame Lager, Farmen oder Türen.

## Sicherungstypen {id="chestprotect-group-types"}

Eine Gruppe kann Sicherungstypen enthalten, z. B. Truhe, Fass oder Ofen. Neue Sicherungen dieser Typen können der
Gruppe automatisch zugewiesen werden.

## Standardgruppe {id="chestprotect-group-default"}

Sicherungen, die keiner anderen Gruppe zugewiesen sind, nutzen die Standardgruppe. Sie kann nicht gelöscht werden.

> Du kannst beliebig viele Gruppen erstellen. Eine Gruppe kann maximal 20 Mitglieder enthalten.
