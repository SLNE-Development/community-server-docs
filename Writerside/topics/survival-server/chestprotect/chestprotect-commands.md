# Befehle

## Befehle von Chestprotect {id="chestprotect-commands"}

Alle Befehle beginnen mit `/chestprotect`.

| Befehl                           | Beschreibung                                                    |
|----------------------------------|-----------------------------------------------------------------|
| `/chestprotect menu`             | Öffnet das Hauptmenü.                                           |
| `/chestprotect lock`             | Sichert ein Objekt oder hebt den Modus wieder auf (Umschalten). |
| `/chestprotect unlock`           | Hebt die Sicherung eines Objekts auf (Umschalten).              |
| `/chestprotect trust <player>`   | Vertraut einem Spieler auf einer Sicherung.                     |
| `/chestprotect untrust <player>` | Entfernt einen vertrauten Spieler von einer Sicherung.          |
| `/chestprotect view`             | Zeigt Sicherungen in deiner Nähe an.                            |
| `/chestprotect exit`             | Beendet den aktuellen Klick-Modus.                              |
| `/chestprotect help`             | Zeigt die Befehle an, die du nutzen kannst.                     |

## Kurzbefehle {id="chestprotect-aliases"}

Für häufig genutzte Befehle gibt es Kurzformen:

| Kurzbefehl             | Entspricht                       |
|------------------------|----------------------------------|
| `/cp`                  | `/chestprotect`                  |
| `/lock`                | `/chestprotect lock`             |
| `/unlock`              | `/chestprotect unlock`           |
| `/trust <player>`      | `/chestprotect trust <player>`   |
| `/untrust <player>`    | `/chestprotect untrust <player>` |

## Klick-Modi {id="chestprotect-click-modes"}

Die Befehle `lock`, `unlock`, `trust` und `untrust` warten darauf, dass du auf ein Objekt klickst. Mit
`/chestprotect exit` brichst du den Modus ab. Alternativ führst du denselben Befehl erneut aus, um den Modus
auszuschalten.

> Die Hilfe zeigt dir nur die Befehle an, die du auch nutzen darfst.
>
