# XP-Event: 100 Millionen XP

## Über das Event {id="general-info"}

Beim XP-Event arbeitet die gesamte Community auf ein gemeinsames Ziel hin: **100 000 000 XP sammeln
und abgeben**.

Am Spawn befindet sich ein großes XP-Gefäß, das sich mit dem Fortschritt der Community immer weiter
füllt. Rund um das Gefäß befinden sich vier Abgabestellen, an denen du deine gesammelten XP
einzahlen kannst.

![XP-Event spawn](xp-event-spawn.png)

Das Ziel muss bis zum Ende des Events erreicht werden. Schafft die Community die **100 Millionen
XP** rechtzeitig, ist die Herausforderung bestanden.

## Eventzeiten {id="event-times"}

Das Event findet an zwei Tagen statt:

| Tag                     | Zeitraum                |
|-------------------------|-------------------------|
| **Samstag, 26.09.2026** | **12:00 bis 00:00 Uhr** |
| **Sonntag, 27.09.2026** | **10:00 bis 22:00 Uhr** |

Zwischen den beiden Zeiträumen ist der Event-Server geschlossen. Am Sonntag um **22:00 Uhr** endet
das Event, sofern das Ziel nicht bereits vorher erreicht wurde.

> Der bisherige Fortschritt bleibt über die Pause zwischen Samstag und Sonntag erhalten.
>
{style="note"}

## XP sammeln {id="collect-xp"}

Du kannst Erfahrung auf den üblichen Wegen in Minecraft sammeln, beispielsweise durch das Töten von
Mobs, den Abbau von Erzen, Angeln, Schmelzen oder das Züchten von Tieren.

Wie du deine XP sammelst, bleibt dir überlassen.

## XP abgeben {id="deposit-xp"}

Damit deine gesammelten XP zum gemeinsamen Ziel zählen, musst du sie am Spawn abgeben.

Dort befinden sich rund um das große XP-Gefäß **vier Abgabestellen**. Stelle dich einfach auf einen
der gekennzeichneten Abgabe-Blöcke. Deine gespeicherten XP werden anschließend automatisch abgezogen
und dem gemeinsamen Fortschritt gutgeschrieben.

![XP-Event deposit](xp-event-deposit.png)

> Nur abgegebene XP zählen zu den **100 000 000 XP**.
>
{style="note"}

## Powerups {id="powerups"}

Während des Events können beim Sammeln von XP besondere **Powerups** gefunden werden.

Powerups gehören jeweils zu einer bestimmten XP-Quelle, beispielsweise zu einem bestimmten Mob,
einem Erz oder einer Aktivität wie Angeln. Solange ein Powerup aktiv ist, erhältst du aus dieser
Quelle zusätzliche XP.

Ein aktives Powerup gilt immer für **alle Spieler auf dem Server**, unabhängig davon, wer es
gefunden hat.

## Teleportation und Homes {id="teleportation"}

Damit du dich leichter auf dem Event-Server bewegen und mit anderen Spielern zusammenspielen kannst,
stehen dir verschiedene Teleportationsbefehle zur Verfügung.

`/spawn`
: Teleportiert dich zum Spawn und den Abgabestellen.

`/tpa <player>`
: Sendet dem angegebenen Spieler eine Teleportationsanfrage.

`/tpaccept`
: Akzeptiert eine eingehende Teleportationsanfrage.

`/sethome`
: Setzt einen Home-Punkt an deiner aktuellen Position.

`/home`
: Teleportiert dich zu deinem Home-Punkt.

## Häufige Fragen {id="q-a"}

{collapsible="true" default-state="collapsed"}
Was ist das Ziel des Events? {id="event-goal"}
: Die Community muss gemeinsam **100 000 000 XP** sammeln und an den Abgabestellen einzahlen.

Wann findet das Event statt? {id="event-date"}
: Das Event läuft am **Samstag, den 26.09.2026, von 12:00 bis 00:00 Uhr** und am **Sonntag, den
27.09.2026, von 10:00 bis 22:00 Uhr**.

Was passiert zwischen Samstag und Sonntag? {id="event-break"}
: Der Event-Server ist in dieser Zeit geschlossen. Der bereits erreichte Fortschritt bleibt erhalten
und das Event wird am Sonntag um 10:00 Uhr fortgesetzt.

Wie gebe ich meine XP ab? {id="event-deposit"}
: Am Spawn befinden sich rund um das große XP-Gefäß vier Abgabestellen. Stelle dich auf einen der
gekennzeichneten Abgabe-Blöcke, um deine XP einzuzahlen.

Muss ich meine XP abgeben, damit sie zählen? {id="event-xp-count"}
: Ja. Nur XP, die du an einer Abgabestelle eingezahlt hast, zählen zu den 100 Millionen XP.

Was sind Powerups? {id="event-powerups"}
: Powerups können beim Sammeln von XP gefunden werden und erhöhen für eine begrenzte Zeit die XP
einer bestimmten Quelle. Der Bonus gilt für alle Spieler auf dem Server.

Was passiert, wenn die 100 Millionen XP erreicht werden? {id="event-goal-reached"}
: Sobald insgesamt **100 000 000 XP** abgegeben wurden, ist das gemeinsame Ziel erreicht und die
Herausforderung erfolgreich abgeschlossen.

Was passiert, wenn das Ziel nicht erreicht wird? {id="event-goal-failed"}
: Am Sonntag um **22:00 Uhr** endet das Event. Wurden bis dahin weniger als 100 Millionen XP
abgegeben, wurde das gemeinsame Ziel nicht erreicht.

Welche Version von Minecraft wird benötigt? {id="event-version"}
: Das Event wird in der Version **26.3** stattfinden.

Was passiert, wenn ich gegen die Regeln verstoße? {id="event-rules"}
: Regelverstöße können zum Ausschluss vom Server führen. Halte dich an die [Serverregeln](rules.md).

Kann ich dem Event auch später noch beitreten? {id="event-join-later"}
: Ja, auch wenn das Event bereits begonnen hat, kannst du jederzeit dem Event beitreten. Wenn
allerdings die maximale
Spieleranzahl erreicht ist, kann es sein, dass du dich in die Warteschlange einreihen musst.
